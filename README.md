## Ular Tangga Pahlawan
<img width="2417" height="1495" alt="{1BB165DE-8298-499A-989D-EFEB168156D9}" src="https://github.com/user-attachments/assets/c0b0a259-bb1e-4d6c-a41e-e717b7b7fe58" />
Permainan ular tangga HTML dengan kuis sejarah. Project ini dibuat untuk keperluan pemenuhan tugas kelompok sejarah, membuat produk atau karya terkait materi Masa Pergerakan Nasional

### Fitur Utama
- **Multipemain**: Ajak teman untuk mainkan bersama
- **Foto Pahlawan** : Penanda khusus untuk tiap pemain, mengingat tokoh-tokoh berjasa
- **Poin & Kuis** : Kumpulkan poin sebanyak-banyaknya, jawab kuis dengan benar
- **Simpan Halaman** : Download HTML dan assets untuk memainkan secara offline

### Penggunaan
1. Buka https://kemalsyabaniadama.github.com/Ular-Tangga-Pahlawan
2. Pilih jumlah pemain. Ajak teman sekitar untuk ikut bermain
3. Klik untuk kocok dadu sesuai giliran pemain
4. Jawab kuis dengan benar, lalu lanjut untuk giliran pemain berikutnya
5. Pemain yang mencapai titik 100 akan dimunculkan popup skor dan kemenangan
